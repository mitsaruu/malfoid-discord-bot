# Malfoid Discord Bot на Rust

Discord-бот на Rust. Настройки находятся в `config/settings.ini`, данные — в `levels.db`.

Команды подтверждаются до длительных запросов, а кнопки — до работы с плеером или базой.
Запуск Activity (`/games` и «Играть!») использует собственный первый ответ.
Проверка канала для игр берёт данные из события Discord и памяти бота без запроса к API.
В ошибках команд указываются команда, сервер, канал, пользователь и время с момента вызова;
временные токены взаимодействий в URL скрываются.

Gemini повторяет запросы при перегрузке и сетевых сбоях, затем пробует запасную модель из `settings.ini`.
Один HTTP-запрос ограничен 60 секундами, для Hydrogen — 300 секундами. Вся генерация ограничена
180 секундами, а при выбранной или запасной Hydrogen — 660 секундами. При наличии запасной модели
для неё резервируется половина общего времени. Некорректные запросы (например, HTTP 400) не повторяются.
Лимит ответа Hydrogen — 32 768 токенов вместе с рассуждением, остальных моделей — 8192.
Явные просьбы о подробном конспекте, таблицах или LaTeX сохраняют структуру ответа даже при `one_line_answers = on`.

`/ask` принимает необязательные `model` (Авто, Flash-Lite, Hydrogen) и `thinking` (low, medium, high).
Без выбора действуют настройки бота. Явный выбор использует только указанную модель.
Hydrogen доступна каждому пользователю четыре успешных ответа в сутки: лимит общий для всех серверов,
включает автоматический переход с основной модели и сохраняется после перезапуска. Сброс — 00:00 МСК;
Ошибки, пустые ответы и отмена до отправки в Discord не расходуют квоту. Остаток показывает `/ai_limits`.
Фоновые генерации не используют Hydrogen без пользовательской квоты.

Малфоид отвечает на обращения, содержащие мат или оскорбления. Администратор сервера может явно
попросить выдать варн, назначить или снять тайм-аут. Бот проверяет права и иерархию ролей.

`/shar` анализирует вопрос через Flash-Lite и выбирает один из 64 готовых ответов. Время анализа ограничено
12 секундами; при ошибке, неверном индексе, отсутствии ключа или исчерпанном личном лимите выбирается
случайный готовый ответ. Произвольный текст модели в ответ шара не попадает.

## Возможности

Секретный кейс стоит по умолчанию **25 000 монет** (`[pets] secret_case_price`). Шансы:
эпический — 60%, легендарный — 34,95%, мифический — 5%, секретный — 0,05%.
🌟 **Стеллочка** — единственный секретный питомец, 1500 монет/ч на первом уровне; выпадает только из секретного кейса.
🧚 **Фоидка романа** — мифический питомец, 550/ч. 🐕 **Даня собака** — легендарный, 170/ч.
Внутри редкости виды выбираются равновероятно; шансы редкостей старых кейсов сохранены.

## Что нужно для сборки
- Rust (https://rustup.rs).
- **CMake** — для музыки (собирает звуковой кодек Opus): https://cmake.org/download/ или `winget install Kitware.CMake`.
  На Linux: `sudo apt install cmake build-essential`.
- Для музыки при работе: `yt-dlp` и `deno`. Установить yt-dlp в venv можно через `requirements.txt`.

## Сборка и тесты
```
cargo test                          # тесты
cargo test -- --ignored             # с интернетом: yt-dlp, Spotify, Викисловарь, погода, Gemini (нужен GEMINI_API_KEY)
cargo build --release               # бот целиком (нужен CMake)
cargo build --release --no-default-features   # без музыки (CMake не нужен)
```
Готовый файл — `target/release/musicbot` (на Windows — `musicbot.exe`).

## Запуск
Бот берёт настройки из переменных окружения:
- `DISCORD_TOKEN` — токен бота (обязательно);
- `TEST_GUILD_ID` — id сервера для проверки: команды появятся только на нём и сразу;
- `REGISTER_GLOBAL=1` — зарегистрировать команды глобально (команда запуска мини-приложения, Entry Point, сохраняется). Нужно один раз после обновления — потом можно убрать;
- `BOT_DIR` — папка с `config/` и `levels.db` (по умолчанию — текущая или папка выше);
- `GEMINI_API_KEY` — ключ Gemini для ИИ (без него `/ask`, `/summary` и `/quiz` отвечают, что ИИ не настроен);
- `DISCORD_CLIENT_SECRET` — секрет приложения (Developer Portal → OAuth2) для мини-приложения игр в слова;
  без него `/games` отвечает, что мини-приложение не настроено;
- `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET` — ключи Spotify API (необязательно: без них ссылки Spotify читаются со страницы плеера);
- `YTDLP` — как запускать yt-dlp. Не задано — бот берёт `venv/bin/python -m yt_dlp` из папки бота, а если venv нет — `yt-dlp`.

Боту нужно разрешение в Developer Portal → Bot: **Message Content Intent**.
Приветствия новичков и команда `/welcome_channel` удалены; Server Members Intent больше не запрашивается.

Для проверки лучше создать в Developer Portal отдельного тестового бота. Запускайте его с отдельным токеном, `TEST_GUILD_ID` и своим `BOT_DIR`.

## QoL: музыка и удобство команд

- `/help`: справка по пяти разделам с примерами и кнопками навигации. Видна только автору.
- `/nowplaying`: обложка, длительность, автор заявки, источник аудио, размер очереди и ссылка на оригинал.
- `/queue_remove position:3`: удалить свою заявку; участник с правом «Управлять сервером» может удалять чужие.
- `/queue_move from:3 to:1`: переместить трек. `/queue_clear_mine`: убрать только свои заявки.
  Команды редактирования требуют находиться в голосовом канале бота. Старые заявки без автора доступны администратору.
- Spotify: сравнение пяти результатов по названию, исполнителю, длительности (если доступна) и версии.
  Нежелательные live/remix/cover/ускоренные версии получают штраф. Уверенность — эвристика, а не гарантия идентичной записи.
  При сомнении появляются кнопки выбора. Для отдельного трека выбор действует 60 секунд, для трека из альбома/плейлиста — 10 минут;
  остальные треки продолжают играть. Выбрать может только автор заявки.
- Выход из пустого голосового канала через 3 минуты по умолчанию, текущий трек возвращается в очередь.
- `/server_settings`: выбранные каналы, функции, права в текстовом/голосовом канале, состояние ИИ и мини-приложения.
  `/server_settings empty_minutes:5` меняет задержку автовыхода; `empty_minutes:0` выключает его.
- `/remove_all`, `/warns_clear` и продажа любого питомца, кроме обычного, требуют подтверждения.
  Заявки и варны, появившиеся после вопроса, сохраняются. Повторная продажа одного питомца не выплачивает монеты.

Новые поля очереди (`details`, `sort_order`), метаданные плейлистов и таблицы настроек добавляются автоматически при запуске.
Для появления новых команд нужен запуск с `REGISTER_GLOBAL=1` или `TEST_GUILD_ID`.
Перед выкаткой: `cargo test --locked` и `cargo build --release --locked` (на этом ПК Windows может блокировать служебные файлы Rust).

Дополнительная проверка SQL без сборки Rust: `python tests/qol_sql_checks.py` (это не заменяет `cargo test`).

## Избранное и история музыки

- Кнопка ❤️ «В избранное» под карточкой сохраняет именно показанный трек, даже если сейчас уже играет следующий. Повторное нажатие не добавляет дубликат.
- `/favorites` открывает личный список на этом сервере: выбор трека для очереди, удаление, страницы и «Играть всё».
- `/favorites play_all:true` добавляет избранное одной командой (до 200 треков за раз). Для воспроизведения нужно быть в голосовом канале бота, либо бот подключится к вашему каналу.
- `/history` показывает последние 500 действительно начавших играть треков сервера, время и автора заявки. Выбранную запись можно снова добавить в очередь от своего имени.
- Музыка попадает в историю после более трёх секунд декодированного аудио. Ошибка загрузки не считается прослушиванием; пауза и продолжение не дублируют запись.
- Списки видны только вызвавшему их участнику. История, избранное и привязки кнопок сохраняются в SQLite между перезапусками.

## Игра в слова и ежедневные итоги

- Команда `/games` открывает список игр. Для «Слова дня» выберите русский или немецкий на экране игры. Бот запоминает выбор, а новый игрок начинает с русского.
- В мини-приложении по-прежнему можно переключать язык. Слова, результаты, статистика и награды для каждого языка отдельные. Старые кнопки «Играть!» продолжают открывать соответствующий язык.
- Новое слово обоих языков начинается **в 00:00 Europe/Moscow**. В это же время запускается отправка результатов закрытого дня: лучшие попытки с короной, проигрыши, незавершённые партии, серия дней сервера, аватары и цветные поля без букв. Ответ скрыт спойлером.
- Канал для итогов — выбранный `/games_channel`, иначе сохранённый канал игры. Публикация не зависит от нового игрока. При большом числе участников результат разбивается на небольшие страницы с кнопкой запуска.
- После перезапуска бот догоняет итоги последнего закрытого дня и недоставленные страницы. Ошибка Discord оставляет страницу для повторной попытки; успешно отправленные страницы повторно не публикуются. Фактическая доставка в полночь зависит от доступности Discord и сети.
- Настройки словарей, наград и `announce` остались в `[wortspiel]` и `[slovo]`. В Rust оба языка используют московские сутки независимо от старого значения `timezone`.

## Автоматические резервные копии

Бот ежедневно в 04:00 по Москве сохраняет согласованный снимок SQLite через online backup API и проверяет его целостность. При запуске без свежей копии делает её сразу. Настройка `[backups]` в `config/settings.ini`:

```ini
[backups]
time = 04:00
keep = 7
```

Копии хранятся локально в `backups/auto/`. В каждой — `levels.db`, обычные текстовые файлы настроек/словарей и страницы мини-приложения, патчноуты и `manifest.json`. `.env`, ключи, журналы, исполняемые файлы и символические ссылки не копируются. Файлы с обнаруженными присвоениями ключей/токенов также исключаются.

Новая копия появляется только после успешной проверки; лишь затем удаляются собственные старые копии сверх `keep`. При сбое предыдущие копии остаются, повторная попытка — через 10 минут. На Linux каталог доступен только владельцу. Копии находятся на том же сервере; для защиты от потери сервера нужно отдельно хранить их на другом устройстве.

Восстановление выполняется при остановленном боте: проверить выбранную копию, сохранить текущую базу отдельно и заменить `levels.db` проверенной копией, убрав устаревшие `levels.db-wal`/`levels.db-shm`, затем запустить службу. Автоматического отката базы нет.

Для регистрации обновлённого списка команд требуется однократный запуск с `REGISTER_GLOBAL=1`; Entry Point мини-приложения сохраняется. Старые партии и статистика не сбрасываются.

## Музыка: очередь, поиск и восстановление

- `/queue` показывает всю очередь по 10 треков на странице. Автор сообщения переключает страницы, выбирает заявку и удаляет или перемещает её кнопками. Для редактирования нужен голосовой канал бота; чужие заявки меняет участник с «Управлять сервером». Устаревшая страница обновляется без изменения другой заявки.
- `/play название` предлагает до пяти результатов с длительностью и кнопкой отмены. Выбор доступен автору 60 секунд. Прямая ссылка запускается сразу, для Spotify сохраняется проверка совпадения версии.
- Метаданные поиска кэшируются на 10 минут; одинаковые одновременные поиски используют один запрос. Прямые ссылки аудиопотока в кэше не хранятся. Размер кэша ограничен 128 запросами.
- Бот заранее получает метаданные одной следующей неразрешённой заявки на сервере. Изменение очереди отменяет старую подготовку; целые песни заранее не скачиваются.
- Текущая заявка сохраняется в SQLite до загрузки аудио. После аварийного перезапуска она возвращается в начало очереди один раз. Бот самостоятельно не входит в голосовой канал: продолжение через `/resume`. Пропущенные или закончившиеся треки не восстанавливаются.

## Отдельный музыкальный канал и диагностика

`/music_channel channel:#музыка` с правом «Управлять сервером» ограничивает музыкальные команды и кнопки выбранным текстовым каналом и его ветками. `/music_channel` без параметра снимает ограничение. Настройка сохраняется в базе независимо от `/games_channel`; `/top_chart_month` относится к музыке. Пока музыкальный канал не выбран, музыка разрешена везде.

`/status` виден только вызвавшему участнику и доступен в любом канале. Показывает измеренную задержку Discord, время работы, состояние музыки, очередь, автоплей и краткую последнюю ошибку данного сервера. Сведения о проверенной автоматической копии доступны с правом «Управлять сервером». Время отображается по Москве. Ключи и пути к системным файлам в статус не попадают.

`/shar` содержит 64 разных ответа: положительные, отрицательные, неопределённые и шуточные.
