# Выбор ИИ и адресная модерация

Согласовано пользователем 17.11.2026: `/ask` получает необязательные модель (Авто, Flash-Lite, Hydrogen) и уровень (low, medium, high). Без параметров сохраняются текущие настройки. Явный выбор не переключается на другую модель.

Hydrogen: четыре успешных ответа каждому пользователю в сутки по Москве, общие для серверов, включая автоматический переход. SQLite сохраняет расход после перезапуска. Одновременные запросы резервируют места; ошибка, пустой ответ и отмена освобождают резерв. Фоновые задачи и `/shar` используют Flash-Lite без Hydrogen; пользовательские упоминания и команды учитывают автора. `/ai_limits` показывает остаток.

Оскорбления: выбран подход распознавания смысла через ИИ вместо совпадения плохих слов. Только прямое серьёзное оскорбление бота в текущем обращении вызывает минутный тайм-аут с первого раза. Цитаты, сообщения о чужих оскорблениях, грубость к другим и лёгкие шутки разрешают ответ. Неоднозначность и ошибка классификации не ведут к наказанию. Проверка применяется в `/ask` и обычных обращениях к боту, не сканирует весь сервер. Сохраняются ограничения Discord по правам и иерархии ролей.

`/shar`: Flash-Lite анализирует вопрос и выбирает индекс существующего ответа. Произвольный сгенерированный текст не публикуется; неверный индекс/ошибка/отсутствие ключа дают случайный готовый ответ. Короткий бюджет ожидания, отключённые упоминания из вопроса.

Выбор реализации: отдельные параметры каждого запроса без изменения глобального состояния; SQLite-резервирование вместо счётчика в памяти; классификация отдельно от ответа, чтобы текст диалога не мог непосредственно запускать тайм-ауты. Локальная эвристика отвергнута из-за цитат и неоднозначного адресата. Публикация и выкладка отдельно, по явному запросу пользователя.
