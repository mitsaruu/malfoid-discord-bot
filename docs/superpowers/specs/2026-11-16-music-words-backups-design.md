# Избранное, история, ежедневные итоги и резервные копии

## Запрос

Добавить личное избранное музыки, историю прослушивания сервера, автоматические резервные копии и ежедневную публикацию итогов игры в слова с аватарами и полями участников. Объединить `/slovo` и `/wort` в одну команду. Продолжать Rust-версию; сохранить существующие данные и три ранее внесённых исправления сборки.

## Предлагаемое поведение

- `/words [language]` открывает одно мини-приложение. Русский и немецкий остаются независимыми словами дня, языки можно переключать внутри игры. При отсутствии параметра используется последний выбранный язык, для нового игрока — русский. Старые кнопки под сообщениями продолжают работать.
- По уточнению пользователя ежедневные итоги обоих языков запускаются ровно в 00:00 Europe/Moscow, после закрытия предыдущего дня. Смена слова обоих языков тоже использует московскую полночь, чтобы немецкий ответ не публиковался раньше окончания дня. Канал фиксируется при игре и хранится в SQLite; при настроенном канале игр используется он. Повторный запуск не дублирует опубликованные страницы итогов. Пропущенный последний день догоняется после запуска. Результаты не зависят от появления нового игрока. Доставка сообщения зависит от доступности Discord; ошибки повторяются, а не считаются успешной отправкой.
- Итоги: дата/номер игры, серия успешных дней сервера, группы игроков по попыткам (лучший результат отмечен короной), проигрыши и незавершённые партии отдельно; общая картинка с аватарами и цветными полями без букв; кнопка «Играть!». Большие списки разбиваются на сообщения и изображения ограниченного размера. Ответ вчерашнего дня — только под спойлером. Еженедельный турнир и дополнительные денежные награды в этот этап не входят.
- Кнопка ❤️ под текущим треком сохраняет его в личное избранное нажавшего пользователя. `/favorites` показывает личные треки с выбором воспроизведения и удаления. Избранное хранится между перезапусками, одинаковая исходная ссылка не создаёт дубликат. Чужое избранное недоступно через кнопки. Для воспроизведения применяется тот же вход в голосовой канал и путь очереди, что у `/play`.
- `/history` показывает последние действительно запущенные треки сервера: время, название и автора заявки. Выбор «Добавить снова» создаёт новую заявку с текущим автором, сохраняя исходную ссылку/метаданные. Неудачный запуск и добавление в очередь не считаются прослушиванием. История ограничена 500 записями на сервер; страницы и кнопки доступны после раннего подтверждения interaction.
- Автоматическая копия раз в сутки (по умолчанию 04:00 Europe/Moscow); при запуске без свежей копии — создать её. Согласованный снимок SQLite через online backup API, затем проверка целостности. Копировать обычные файлы из `config/`, `patchnotes.txt`, мини-приложение и сведения о версии; не копировать `.env`, ключи, токены, журналы, исполняемые файлы. Завершённая копия появляется атомарно, старые копии удаляются только после успешного завершения новой. Хранить последние 7 копий; сбой сохраняет предыдущие копии и повторяется позднее. Доступ к каталогу только владельцу. Это локальные копии на том же сервере.

## Подходы

1. Продолжить текущий Rust-бот: небольшие модули для музыкальной библиотеки, итогов и резервных копий, SQLite для долговечных данных, существующий рендер карточек и текущие фоновые задачи. Рекомендуется: не нужны новые сервисы и отдельная настройка Discord.
2. Отдельные cron-скрипты для итогов и копий: меньше изменений основного процесса, но дублируются доступ к Discord, правила игры и конфигурация. Для этого обновления не выбирается.

Пользователь уточнил единственное изменение предложения: итоги ровно в 00:00 по Москве. Предложение принято с этой поправкой; `/words`, остальные правила и хранение 7 копий — рабочие значения этого этапа. Выбран подход продолжения существующего Rust-бота.

## Проверки и ограничения

Проверить изоляцию пользователей и серверов, повторные нажатия, новый автор повторной заявки, ограничение истории, неуспешный запуск, восстановление расписания после перезапуска, границы суток и часовые пояса, отсутствие повторов и спойлеров, корректность копии SQLite с WAL и безопасное удаление только собственных старых копий. Проверить регистрацию одной команды слов и сохранение старых кнопок. Скомпилировать и запустить весь набор тестов на Linux в отдельном каталоге без токенов и без перезапуска рабочего бота, если Windows снова блокирует Rust.

Публикация на GitHub и установка на рабочий сервер не входят в текущий запрос без отдельного указания пользователя.
